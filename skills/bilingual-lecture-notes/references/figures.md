# Figures

## One shared, language-neutral file

- Every figure is a macro `\fig<Name>` in `figures.tex`, which both editions
  `\input` after defining their word macros. The same file draws the same
  picture with the same number in both editions.
- **No word is typed inside a figure.** Axis labels, annotations and legends
  are `\lbl<Name>` macros, defined in each edition's preamble:
  ```latex
  % notes-en.tex                              % notes-ko.tex
  \newcommand{\lblPosition}{position $x$}     \newcommand{\lblPosition}{위치 $x$}
  \newcommand{\lblSpreads}{width grows\\like $\sqrt{Dt}$}
                                              \newcommand{\lblSpreads}{폭은 $\sqrt{Dt}$에\\비례해 커진다}
  ```
  A new figure word goes into **both** preambles in the same edit. Never fork
  a figure per language. Some repositories keep the words in
  `figwords-en.tex` / `figwords-ko.tex` instead of the preambles.
- Only the `\caption{…}` text lives in the editions.
- Figures are added in the order they first appear, under a comment header
  `%% ===== (N) what it shows ====`, so a count of figures is a grep away.

## Drawing rules

- **Black and grey only.** Curves are told apart by line style (solid, dashed,
  dotted, dash-dot) and by direct labels next to the curves, not by colour
  and preferably not by a legend box.
- **Computed, not sketched.** A plotted curve is computed from the formula the
  caption states, with TikZ `plot` or pgfplots, over a domain that shows its
  features (asymptotes, crossings, maxima). Check a couple of values by hand.
- Schematic diagrams (a piston, a cycle on a PV plane, energy levels, a
  light cone) are fine as schematics, but their geometry must be consistent:
  adiabats steeper than isotherms, levels in the right order, arrows in the
  direction the text says.
- Sizes: up to the text width; typical `x=0.9cm`. Use `\footnotesize` for
  labels inside the figure.
- Arrow tips from `arrows.meta` (`>=Stealth`).

## Large or generated figures

- Simulation snapshots and many-point data are generated by a script and saved
  either as a macro holding the coordinates or as a **1-bit PNG** in `img/`
  (small, prints sharply). Say in a comment above the macro which script
  produced it and with what parameters.
- Files a figure reads (`\includegraphics`, `table {file}`) are listed in the
  repository README. In an assembled layout the assembly script checks that no
  figure reaches outside its part.

## Check every figure by looking at it

Render the page (`pdftoppm -r 110 -f N -l N -png …`) in **both** editions:
Korean words are wider and can collide with curves or run off the frame. Fix
by moving the label anchor, breaking the label with `\\` and `align=center`,
or shortening the word in that edition.

Common fixes seen:

- An axis label at `node[below left]` collided with the last tick label; put
  it at `node[right]` past the arrow tip.
- Labels placed for the English words overlapped a curve in Korean; place
  labels in regions the curve does not enter.

## Counting

The report gives the figure count; `grep -c '^%% =====' figures.tex` gives it
when the headers are kept.
